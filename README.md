# 自然语言电商 —— 对话式推荐智能体（LLM4Rec）

**用自然语言完成购物**：不只推荐，还能说话完成收藏、加购、下单。定位如淘宝，交互方式换成对话——"想买个写代码的笔记本，七千左右，32G 内存"，系统追问澄清、检索候选、LLM 重排并给出带理由的推荐，支持"为什么没推 X"反事实解释；"收藏第一款""第二款加入购物车""下单"直接说话执行。

> 中软国际 8 周企业实训项目（2026）。团队 5 人。目标：实训高分 + 简历项目 + 完整可落地应用。

## 核心特性

- **自然语言电商**：对话即操作——推荐、收藏、加购、下单、查订单全部能说话完成（`add_to_fav`/`add_to_cart`/`checkout`/`my_orders`/`my_favs` 意图）
- **对话式推荐**：主动澄清（品类→用途→预算→配置）、多轮偏好演化、否定排除、重复抑制
- **可解释推荐**：理由引用用户原话 + 主动披露缺点 + 反事实解释"为什么没推 X"（数字对比）
- **完整用户体系**：注册/登录（JWT），**买家 / 商家双角色**；购物车/收藏/订单/会话按用户隔离
- **商家中心**：商品 CRUD + 上下架、营销位配置（促销条/到手价/海报文案/主图上传）、数据看板（曝光→浏览→加购→下单漏斗 + Top10）
- **营销式商品卡片**：一行六列网格，海报主图（商家上传，未传则按文案生成 CSS 海报）+ 价格浮层 + 促销条 + 到手价 + 已省/分期/服务标签 + 回头客与店铺
- **逛商品 + 自然语言搜索**：500 款商品，筛选 + NL 搜索（"7000以内写代码笔记本 32G内存"→ 20 结果）
- **内容协同过滤**：相似商品推荐（ItemCF 内容化变体）
- **text2sql**：LLM 把需求转成真 SQL 查 MySQL（硬约束过滤）
- **评审 Agent**：多 Agent 协作——推荐后校验硬约束/理由一致性/多样性
- **冷启动评测**：LLM 用户模拟器 3 seed × 30 persona，对话式 Success@3 = 38.9%，热门榜仅 1.1%（约 35 倍）

## 架构

```
前端(Vue3 + Element Plus + ECharts)
  买家：对话推荐 / 逛商品 / 商品详情 / 收藏 / 我的导购(购物车·订单·画像)
  商家：商家中心(数据看板 · 商品管理 · 营销位配置)
        │ HTTP（JWT 登录态，token 内含 role）
FastAPI 后端
  ├─ 对话编排：意图分类 → 澄清 → 召回 → LLM 重排 → 解释 / 电商操作
  ├─ 商家服务：商品 CRUD / 营销位 / 主图上传 / 看板聚合（按 merchant_id 隔离）
  ├─ MySQL     users/favorites/products/sessions/cart_items/orders/profiles/product_events
  ├─ ChromaDB 语义检索（bge-m3）
  ├─ text2sql 自然语言 → SQL 查库
  └─ DeepSeek 大模型（意图 / 槽位 / 重排 / 解释 / 评审）
```

## 快速开始

```bash
# 1. 数据库（MySQL 8）
mysql -u root -p < db/schema.sql

# 2. 商品入库 + 商家体系（幂等，可重复执行）
cd dialog-rec-agent
python scripts/migrate_merchant.py       # 补字段 + 500 款商品 + 18 个商家账号 + 默认营销位
                                         # 加 --force 可重置所有营销位

# 3. 后端
cd backend
cp .env.example .env                     # 填 LLM_API_KEY、MYSQL_PASSWORD
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 4. 前端
cd frontend
npm install
npm run dev                              # 打开 http://localhost:5174
```

> 演示商家账号：`merchant01` ~ `merchant18`（按品牌一店一号），密码 `123456`，
> 登录页切到「我是商家」即可进入商家中心。买家注册照旧。
